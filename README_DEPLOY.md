# U.Project Nexus — Website Sementara

Website statis 1 halaman untuk identitas publik U.Project Nexus.

## Struktur
- index.html
- style.css
- script.js
- assets/nexus-logo.png
- assets/mantap-logo.png

## Deploy yang direkomendasikan
Cloudflare Pages terhubung ke GitHub. Website ini tidak membutuhkan backend atau database.

### Cloudflare Pages
1. Buat repository, misalnya `uproject-nexus-website`.
2. Upload seluruh isi folder ini.
3. Cloudflare Dashboard → Workers & Pages → Create → Pages.
4. Hubungkan repository GitHub.
5. Deploy sebagai static site.

### Domain
Sementara dapat memakai domain Pages. Ketika membeli domain resmi, sambungkan domain tersebut melalui menu Custom domains.
